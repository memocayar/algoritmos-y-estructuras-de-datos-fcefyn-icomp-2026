## Cómo seguirlo con tu propio Claude (o la IA que uses)

### 1. Clonar el repo

```bash
git clone https://github.com/memocayar/algoritmos-y-estructuras-de-datos-fcefyn-icomp-2026.git
cd algoritmos-y-estructuras-de-datos-fcefyn-icomp-2026
```

Abrí tu agente (Claude Code, Codex, Gemini CLI, Cursor, etc.) dentro de esa carpeta.

### 2. Conectar el aula virtual con [unc-mcp](https://github.com/maviflora/unc-mcp)

unc-mcp es un servidor MCP no oficial. Le permite a tu agente entrar al aula virtual con tu cuenta, listar tus cursos y leer los archivos. Está probado en FCEFyN. Necesitás [Node.js](https://nodejs.org) 20 o superior.

```bash
# 1. Iniciar sesión (una sola vez): elegí "unc-fcefyn" y entrá con tu mail @mi.unc.edu.ar
npx -y unc-mcp login

# 2. Agregarlo a tu agente
claude mcp add unc -- npx -y unc-mcp      # Claude Code
codex mcp add unc -- npx -y unc-mcp       # Codex
gemini mcp add unc npx -y unc-mcp         # Gemini CLI
```

En **Claude Desktop**, entrá a *Settings → Developer → Edit Config*, agregá esto dentro de `mcpServers` y reiniciá la app:

```json
"unc": { "command": "npx", "args": ["-y", "unc-mcp"] }
```

Para otros clientes (Cursor, VS Code, ChatGPT), seguí la [guía de instalación](https://github.com/maviflora/unc-mcp). Tu usuario y contraseña quedan solo en tu computadora.

### 3. Buscar qué cambió en el aula

Los archivos de este repo se bajaron en el segundo semestre de 2026, así que la cátedra puede haber subido material nuevo o cambiado algo. Pedile a tu agente algo así:

> Con el MCP del aula, listá todo el material del curso de Algoritmos y Estructuras de Datos. Comparalo con lo que hay en este repo (`Material del curso/` y los PDF de la raíz) y decime qué archivos hay en el aula que no están acá, cuáles cambiaron de nombre o de versión, y cuáles están acá pero ya no en el aula. Pasame los links de descarga de los que faltan.

El MCP no puede leer los formatos viejos (.ppt, .doc) ni los .zip. Para esos archivos te va a pasar el link para que los bajes vos.

### 4. Usar las páginas como artifacts de Claude (para que anden los botones)

En GitHub Pages, las páginas de `artifacts/` funcionan, pero los botones que llaman a Claude (corregir código, explicar una pregunta, generar ejercicios nuevos) quedan ocultos, porque necesitan correr dentro de claude.ai. Para tener tu propia copia con esos botones:

1. Abrí **Claude Code** dentro del repo clonado, con tu cuenta de claude.ai.
2. Pedile, por ejemplo:
   > Publicá `artifacts/entrenador-parcial-1/index.html` como un Artifact nuevo con la capacidad `sample`, así funcionan los botones de Claude.

   Hacé lo mismo con cualquier otra página de `artifacts/`. Solo el Entrenador Parcial I usa `sample`. Las demás se publican sin capacidades.
3. Claude te da un link `claude.ai/artifact/...` privado. Ese es tu artifact: tu progreso queda en tu navegador, y la primera vez que uses un botón de Claude te va a pedir permiso. El uso se descuenta de tu plan.

Si usás otra IA, las páginas igual funcionan abiertas en el navegador. Para que te corrija un ejercicio, copiale la consigna, tu código y las pruebas.
